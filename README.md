# REXX RIDER 🏍️

A lightweight browser motorcycle game made with HTML5 Canvas.

## Controls
- **W / ↑** — accelerate
- **S / ↓** — brake
- **A / ←** — move left
- **D / →** — move right
- **SPACE** — nitro
- **ENTER** — restart after crash

## Play
Enable **GitHub Pages** for the `main` branch with the site root set to `/ (root)`. Then open the Pages URL for this repository.
